# Design and Analysis of Algorithms (DAA)

A collection of **Design and Analysis of Algorithms (DAA)** programs implemented in **C** as part of the college laboratory curriculum. This repository serves as a reference for learning fundamental algorithms, understanding their implementation, and preparing for practical examinations.

---

## 📚 About

This repository contains implementations of commonly used algorithms covering various paradigms, including:

- Sorting Algorithms
- Graph Algorithms
- Greedy Algorithms
- Dynamic Programming
- Backtracking
- Divide and Conquer

Each program is written in **C** with an emphasis on clarity and understanding of the underlying algorithm.

---

## 🛠️ Technologies Used

- **Language:** C
- **IDE:** Visual Studio Code
- **Compiler:** GCC

---

## 📂 Algorithms Included

### Sorting Algorithms
- Bubble Sort
- Merge Sort
- Quick Sort
- Randomized Quick Sort
- Heap Sort

### Graph Algorithms
- Breadth First Search (BFS)

### Greedy Algorithms
- Fractional Knapsack

- Matrix Chain Multiplication

### Backtracking
- N-Queens Problem
- Graph Coloring

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/SrinjoyeeDey/DAA-Practical-Exam.git
```

### Navigate to the Project

```bash
cd DAA-Practical-Exam
```

### Compile a Program

```bash
gcc filename.c -o program
```

### Run the Program

```bash
./program
```

> **Windows (MinGW):**
>
> ```bash
> program.exe
> ```
